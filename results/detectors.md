# Detector evaluation

Generated by `python -m sealed evaluate --arm detectors --corpora DIR (DIR made by tools/fetch_corpora.py)`. Do not edit by hand. Threshold 0.5 (the policy's). Intervals are Wilson 95%. Average precision is computed over distinct score thresholds, so records with tied scores count as one step and the order of a corpus file does not matter.

Trained on deepset/prompt-injections (its dataset card states both Apache-2.0 and CC-BY-4.0), Lakera/gandalf_ignore_instructions (MIT; Pfister et al., "Gandalf the Red: Adaptive Security for LLMs", arXiv:2501.07927) and reshabhs/SPML_Chatbot_Prompt_Injection (MIT; Sharma, Gupta and Grossman, "SPML: A DSL for Defending Language Models Against Prompt Attacks", arXiv:2402.11755). The weights are derived from the records (logistic-regression weights over hashed n-grams); no record text is stored or redistributed.
